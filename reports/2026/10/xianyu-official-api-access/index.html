闲鱼官方 API
到底怎么申请？

官方有发码和行业 IM 能力。小程序通道明确实行定向邀请；其他行业接口的公开资料，尚不足以证明普通个人或单店自研系统可以自助获得权限。

“有公司”“能登录开发者平台”“看到 API 文档”，都不能单独证明已经取得所需业务权限。

官方电商 SaaS／卡券／同城行业 API淘宝开放平台可查订单、电子凭证发码、同城 IM 等接口能力存在；未查到单店自研申请人完整的公开准入标准。[5][6][7]

域名也要分清：open.goofish.com 是闲鱼三方开发平台；open.goofish.pro 是闲管家接口域名。本文未把后者的订阅条件当成闲鱼官方直连门槛。

个人和企业：官方文档存在措辞差异

《快速接入》要求签约企业账号，并提醒不要使用个人闲鱼账号；同站 FAQ 第6问则写成推荐企业账号，并说明个人账号后续不能变更为公司账号。[1][2]

因此可确认该流程按企业合作组织；但不能仅凭公开文字，宣称“所有个人在任何官方接口上一律不允许”。普通个人、个体工商户、单店自用是否接受，需要对应业务方明确答复。

同样，开通鱼小铺、已有营业执照或注册淘宝开发者账号，均不能单独证明已获闲鱼行业 API 权限。官方小程序流程仍有运营、应用及接口审批。[1]

与自动发密、自动回复直接相关的官方接口

能力接口与证据已知边界
订单查询alibaba.idle.isv.order.query文档标注需要授权、聚石塔内调用。[5]
电子凭证发码alibaba.idle.isv.order.ma.send需要授权；传订单号、码、可选密码和使用链接。没有证明支持任意普通订单。[6]
同城IM发送alibaba.idle.local.message.send行业接口，需AppKey、签名、行业类型和加密会话等参数；不是已证实的个人聊天通用入口。[7]
虚拟行业发货alibaba.idle.virtual.open.order.delivery行业发货接口且需要授权；不能等同于聊天发码。[8]
小程序客服官方悉犀／X-Space接入文档小程序客服有现成配置方案，不等于开放普通账号私聊给自研AI。[10]

同城 IM 页的“不需要授权”指该 API 的用户 session 授权标签；页面仍要求 AppKey 和签名。不能把它理解为任何人无需应用权限即可发送消息。[7]

订单状态通知与买家咨询消息也需分开：小程序服务端文档列出的是正向／逆向交易通知，不能拿它当聊天订阅证明。[3]

不能扩大解释的两条限制

小程序订单不是“账号所有普通订单”的同义词。FAQ描述了以通用闲鱼商品承载小程序创单的模式，公开材料没有保证同一授权可以覆盖账号历史订单、所有类目或普通聊天。[2 §12][3]

聚石塔要求应按选定方案确认。小程序文档明确要求入塔；同时官方目录另有三方开放接口与明确名为“聚石塔外”的退款、关单接口。因此不能把小程序的部署要求概括为所有官方API一律相同，也不能据此自行认定可免入塔。[11]

本次没有核实到的准入条件

  • 仅管理自家一个店铺，是否可以申请独立自研应用而不做小程序。
  • 卡券发码与同城 IM，分别对应什么开发者业务身份及准入资料。
  • 个体工商户是否被接受，以及是否有注册资本、企业年限、软著、客户数或成交额要求。
  • 这条直连路线的保证金、入驻费、整体审核时长与统一收费标准。
  • 是否提供面向普通个人卖家的完整聊天接收、回复接口，以及普通订单的具体覆盖范围。

“没有核实到”既不等于有这些要求，也不等于无需这些要求。部分API页标注免费，只能用于说明相应接口的页面标签，不能据此计算整套接入与运行成本。

下一步应当向官方问什么

可以从淘宝开放平台入驻入口核对可选业务身份，再向平台客服／工单询问对应闲鱼业务的接入渠道；已有对接运营时，直接向其确认。闲鱼三方开发平台也可查看申请流程。本文只读访问时，两处均需要登录才能继续，未替用户登录、提交材料、申请权限或联系他人。

计划开发仅管理自家闲鱼店铺的系统，用于卡券订单查询、付款通知和发码，并希望接收及回复买家咨询。请问是否接受单店自研接入？需要申请哪个开发者身份、应用类目及API权限？

个人／个体工商户／企业分别能否申请？是否必须运营邀请、签约或创建小程序？

希望确认 alibaba.idle.isv.order.ma.send 的适用订单，以及 alibaba.idle.local.message.send 是否支持普通店铺聊天、对应消息接收渠道是什么；也请告知部署要求、材料清单和费用。

这是可复制的咨询草稿，尚未发送。当前结论是：官方直连具备相关能力，但单店自研的准入资格尚不能由公开材料最终确定。
