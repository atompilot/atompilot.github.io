这些星说明什么

插件壳是这一季的默认形状。DeepSeek Harness 自己 26 万星，桌面端和插件清单再各占一块。别人的新项目也贴着它长：换模型的菜单栏、免登录模型插件、电视和文档工具并不属于这个生态，但编程这一侧的新星大多是壳、插件或本机推理，不是又一个聊天网页。

Google 的 Harness² 把这件事说成研究问题：模型权重固定，要优化的是外面的提示、工具、记忆和编排，而且任务是设计壳的时候没见过的。这和上一份 coding agent 前沿简报里的判断接得上：分差已经不完全在模型本身。

storytold 在两周里连续放出图像、文字、绘图、表格四套「纯 Rust、清洁室重写」。星数很高，公开 issue 也高。本页没有安装或对照原软件，不能把「自称重写了 Photoshop」读成「已经能替换 Photoshop」。

实用小工具涨得同样快。cleanyourtv 11 天超过 4 万星，aerial-tv 8 天 6 千多星，都是电视广告和预装。firecrawl/anydoc（8 月 3 日，约 2.3 万星）把 Word、幻灯片、表格和 PDF 转成 Markdown。人愿意为「去掉讨厌的东西」和「把旧文件交给 agent」按星。

涨得快、本页不展开用法的几类

主机游戏移植也在这张星数表上。AnyPS5 约 4.9 万星。10 月 13 日创建的 seedds/nxnative 约 7,424 星，仓库描述是把 Switch 游戏变成未签名的 iPhone、iPad、Mac 安装包。Zagitta/gpu-unlock（10 月 18 日，约 1.1 万星）自称解锁消费级显卡的指令吞吐。8 月的去水印仓库星数也过万。这些只记现象。本页不写怎么转游戏、怎么改驱动、怎么去掉水印。

免登录、不限量的模型插件同样只记星数。没有逐行看它把请求发到哪里，就不该安装。

来源与适用边界

  • 2026-10-28，GitHub Search：created:>2026-07-01 与 created:>2026-10-01，按星数降序。
  • 同一天用每个仓库的 API 核对星数、创建日、最近推送、语言、许可证和公开 issue 数。表中的星是这次读取的整数。
  • README 只读了开头，用来核对「它自称做什么」：Harness²、openai/math、PhotoCraft。没有克隆仓库，没有运行程序，没有审依赖和网络行为。
  • 星数一天内就会变。公开 issue 为 0 可能是关闭了 issue，不是没有缺陷。
